# Анализ продаж видеоигр в Steam

## Цель

Проверка трёх гипотез о факторах, которые могут влиять на продажи видеоигр в Steam:
1. Зависимость продаж от цены
2. Сравнение оценок пользователей и критиков по жанрам
3. Влияние месяца релиза на продажи

## Данные

Собраны через Steam Spy API и Steam Store API. 8 жанров, после удаления дублей — 2407 уникальных игр. Продажи оценены по количеству отзывов (прокси-метрика).

## Результаты

**Цена.** Выявлена сильная взаимосвязь между ценой игры и продажами (r = 0.95). До 40$ повышение цены значимо увеличивает продажи (p<0.05), после 40 дальнейший рост цены не дает прироста продаж.

**Оценки.** Во всех жанрах пользователи оценивают игры выше критиков. Максимальный разрыв — в Indie (+12 баллов, n=73), минимальный — в Sports (+4 балла, n=428).

**Сезонность.** Месяц выхода игры значимо влияет на продажи (p < 0.05). Лучшие месяцы для релиза — сентябрь и ноябрь, худший — июнь. Осень является наиболее прибыльным сезоном для выпуска новых игр.

## Статистические методы

Из-за ненормального распределения данных использованы непараметрические тесты: Kruskal-Wallis, Mann-Whitney с коррекцией Холма, корреляция Спирмена.

## Ограничения

Анализ выполнен на данных, собранных через открытые API Steam. Продажи оценены косвенно (через количество отзывов). Отсутствует ряд важных метрик (реклама, себестоимость, чистая прибыль и т.д.).
